# knowdrug 知药-代表版

这是与医生端独立的 HTML / CSS / JavaScript 交互演示项目。医生端项目位于同级 `medlink`，本项目不修改医生端文件。

启动：在本目录执行 `python3 -m http.server 8081 --directory dist`，打开 `http://localhost:8081`。

功能：

- 首页：数字人概览、近7/30天服务指标、高频提问主题、待跟进医生和功能统计。
- 数字人：上传本人照片、采集或上传声音样本，完成演示式录入校验；选择欢迎介绍或资料跟进话术，录制或上传对应音频，将照片动效与本人音频合成为可下载视频。支持生成按指定医生归属的代表身份链接、视频链接与复制。
- 医生洞察：基础资料编辑、KOL 分级、认知阶段、商保支付偏好标签及筛选；保留提问总结与跟进笔记，另按邀请链接记录浏览、视频播放、看完和提问的真实本浏览器操作轨迹。
- 知识库：定向导入 TXT / Markdown / JSON，或粘贴资料；仅检索本机内容并引用命中原文与段落，不生成无资料支撑的医疗答案。支持删除资料。
- 统计：周期切换、趋势指标切换、柱状图点击、功能下钻、医生使用排行及 CSV 导出。

数据边界：

- `dist/data.js` 为确定性合成样例，所有人数、提问量、功能次数与图表由同一事件集合计算。
- 代表端未读取医生端的实际使用记录；两端尚无后台数据同步。
- 上传的照片、声音、生成视频、知识库正文、医生标签、分享链接与轨迹保存在当前 origin 的 IndexedDB，不上传到网络或 GitHub。旧版跟进笔记继续保存在 localStorage。清除网站数据会删除这些本地资料。
- 照片/声音录入校验按用户要求为交互演示，只检查可读取的格式，不做人脸识别、真人身份或声纹鉴定。视频使用照片动效加本人录音，未接声音克隆或口型合成服务。录音需安全上下文与麦克风授权，也可上传音频；编码依赖浏览器 MediaRecorder / AudioContext / canvas.captureStream。
- 分享链接的内容保存在原浏览器：需在同 origin、同一浏览器配置文件下预览，不能跨设备分享。页面明确说明此限制，预览按钮不会计入轨迹；普通链接按所选医生归属记录操作，不验证实际浏览者身份。视频文件可下载后另行分享。
- 新增轨迹独立于原有合成统计，不把未发生的浏览或提问记成实际操作。知识库没有预置药品事实或 API 密钥。
- 旧版笔记与跟进状态保留 `knowdrug-representative-` localStorage 命名空间。Sites 和 GitHub Pages 的 origin 不同，浏览器资料不会互通。
- 示例数据不包含患者病例正文。

原型使用与医生端一致的系统中文字体、480px移动布局、底部导航和底部弹层。主色为浅绿色，沿用现有生成的虚拟代表肖像。

当前演示药品统一为日达仙。相关条目为资料阅读框架与交互样例，不增加具体适应症或用药剂量信息。


## 本机交互检查

执行 `npm ci && npm test`。开发依赖仅用于 DOM / IndexedDB 流程检查，线上页面不依赖 npm 包。检查覆盖定向资料检索与无命中、医生标签持久化和筛选、身份/视频链接、浏览/播放/看完/提问回写、预览排除、失效链接及输入转义。实际麦克风、音频解码、视频编码和移动设备显示仍需浏览器人工体验。
