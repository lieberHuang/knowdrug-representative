# knowdrug 知药-代表版

这是与医生端独立的 HTML / CSS / JavaScript 交互演示项目。医生端项目位于同级 `medlink`，本项目不修改医生端文件。

启动：在本目录执行 `python3 -m http.server 8081 --directory dist`，打开 `http://localhost:8081`。

功能：

- 首页：数字人概览、近7/30天服务指标、高频提问主题。
- 数字人：未建立形象时展示创建引导；已有形象后展示已生成视频，并引导创建新的介绍视频；尚无视频时引导生成首个视频。页面不展示三步进度条。第一步填写姓名并上传照片，校验通过后点击下一步进入声纹采集；照片与声纹检查均显示 loading 弹窗，完成后建立数字人。选择欢迎介绍或资料跟进话术，录制或上传对应音频，将照片动效与本人音频合成为可下载视频。支持生成按指定医生归属的代表身份链接、视频链接与复制。
- 医生洞察：默认医生列表与搜索，不再提供最近 7 天时间线和标签筛选；医生详情仅汇总对应医生的创支申请人数、已开通和处理中数量，不展示患者列表与详情；保留提问总结，移除功能使用和跟进记录卡片，另按邀请链接记录浏览、视频播放、看完和提问的真实本浏览器操作轨迹。
- 知识库：日达仙聊天助手：在输入框上方切换药品专家、保险专家和合规专家，各专家独立保存对话及输入草稿，展示各自推荐问题；每条回答后提供三个可点击追问的问题。支持连续提问、整理资料状态、复制回答与新建当前专家的问答。前端不再提供资料导入与管理；如本浏览器已有私有资料，则保留原文检索和引用，没有命中时展示资料阅读框架，不编造药品适应症或剂量。
- 我的：顶部头像进入“我的”，可管理数字人并注销。注销确认后，清除代表端 IndexedDB 全部记录和 `knowdrug-representative-` localStorage 记录，停止录音/生成、释放媒体 URL，回到照片上传步骤。医生端的存储不受影响。已打开的同源页面通过 BroadcastChannel 接收注销状态，原分享链接失效。
- 统计：周期切换、趋势指标切换、柱状图点击、功能下钻、医生使用排行及 CSV 导出。

数据边界：

- `dist/data.js` 为确定性合成样例，提问量、功能次数与图表由同一事件集合计算。`PAYMENT_APPLICATIONS` 为按 doctorId 关联的匿名创支申请记录，审核和服务状态均为本机交互资料，不连接真实支付/审核系统；统计由对应医生的申请记录计算。
- 代表端未读取医生端的实际使用记录；两端尚无后台数据同步。
- 上传的照片、声音、生成视频、知识库正文、医生标签、分享链接与轨迹保存在当前 origin 的 IndexedDB，不上传到网络或 GitHub。旧版跟进笔记继续保存在 localStorage。清除网站数据会删除这些本地资料。
- 照片/声音录入校验按用户要求为交互演示，只检查可读取的格式，不做人脸识别、真人身份或声纹鉴定。视频使用照片动效加本人录音，未接声音克隆或口型合成服务。录音需安全上下文与麦克风授权，也可上传音频；编码依赖浏览器 MediaRecorder / AudioContext / canvas.captureStream。
- 分享链接的内容保存在原浏览器：需在同 origin、同一浏览器配置文件下预览，不能跨设备分享。页面明确说明此限制，预览按钮不会计入轨迹；普通链接按所选医生归属记录操作，不验证实际浏览者身份。视频文件可下载后另行分享。
- 新增轨迹独立于原有合成统计，不把未发生的浏览或提问记成实际操作。知识库没有预置药品事实或 API 密钥。
- 旧版笔记与跟进状态保留 `knowdrug-representative-` localStorage 命名空间。Sites 和 GitHub Pages 的 origin 不同，浏览器资料不会互通。
- 示例数据不包含患者病例正文。

原型使用与医生端一致的系统中文字体、480px移动布局、底部导航和底部弹层。主色为浅绿色，沿用现有生成的虚拟代表肖像。

当前演示药品统一为日达仙。相关条目为资料阅读框架与交互样例，不增加具体适应症或用药剂量信息。


## 本机交互检查

执行 `npm ci && npm test`。开发依赖仅用于 DOM / IndexedDB 流程检查，线上页面不依赖 npm 包。检查覆盖照片/声纹分步录入和 loading 弹窗、聊天检索与引用、数字人三种状态、医生列表与搜索、按医生归属的创支汇总、三专家切换与并发回答、每条回答的三个追问、分享轨迹、注销后清空历史与失效链接、待回答任务取消，以及保留医生端存储。实际麦克风、音频解码、视频编码和移动设备显示仍需浏览器人工体验。

## 手机兼容增强

- 使用测量的视口高度替代对动态视口单位的单一依赖，处理地址栏和软键盘变化；补充短屏、横屏及 320–360 px 窄屏样式。
- 对缺少原生 dialog 的浏览器提供本机弹窗回退，包含遮罩、焦点约束、关闭与嵌套弹层；对缺少 randomUUID 的浏览器使用 getRandomValues 生成标识，移除 Object.hasOwn / Array.at 依赖。
- 自动化检查模拟 320×568、360×640、375×667、390×844、430×932、480×800、667×375、844×390 视口以及键盘偏移，分别执行原生弹窗和回退弹窗的业务流程。该检查不进行真实浏览器像素布局。
- 当前浏览器预览服务超时，尚未完成 iPhone / 安卓 / 微信内置浏览器的实机截图验收；语音识别、录音和视频生成仍受浏览器能力及授权限制。

手机展示使用约 219 KB 的 `assets/representative.jpg`，替代直接加载约 1.8 MB 的 PNG；原始 PNG 仅作为创作素材保留。
